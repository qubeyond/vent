# Changelog

## v0.2.1

- Честные этапы обработки на странице записи: статус пишется в БД (`queued`/`correcting`/`tagging`) и коммитится по ходу фоновой задачи, страница опрашивает и показывает реальный прогресс — не таймер-симуляцию, как раньше на отдельной странице «Создание». Закрыть вкладку по-прежнему безопасно — обработка идёт независимо от фронта.
- Поиск по тегам: выбранные теги показываются первыми в списке карточки и подсвечиваются заливкой (вместо старого просто-неприглушения).
- Кнопка «Создать» на мобилках прижата вправо; убрано вертикальное центрирование инпута дампа — тот же класс бага, что раньше чинили на странице заметок (растущий текстареа больше не двигает кнопку под клавиатуру).
- Фильтр по датам: можно вписать дату текстом (`ГГГГ-ММ-ДД`), нативный пикер календаря остался как кнопка рядом.
- Разделитель между временем и счётчиком символов на карточке записи.
- Тумблер «Исправить орфографию и пунктуацию» увеличен на мобилках — и на создании, и на редактировании записи.
- `Makefile` поверх `scripts/*.sh` (`make dev`, `make test`, `make deploy-prod` и т.д.), деплой-воркфлоу переведён на `make deploy-prod`.
- Проверено: баг с пустой страницей при 0 записей/тегов не воспроизводится — у облака тегов и списка заметок уже есть текстовый empty-state, как у облака слов.

## v0.2.0

- Все операции с LLM — создание записи, перетегирование, правка орфографии/пунктуации — переведены на модель очереди: ответ приходит мгновенно (`status: processing`), сама обработка идёт фоновой задачей. Можно закрыть вкладку сразу после отправки, обработка не прервётся.
- Страница записи опрашивает статус, пока идёт обработка, и показывает индикатор; редактирование/перетегирование недоступны, пока запись не готова. Ошибка обработки (например, недоступен LLM-роутер) теперь не теряется, а показывается на странице записи вместо старого поведения с HTTP 502.
- Улучшен промпт тегирования: имя тега больше никогда не совпадает дословно с названием категории — раньше это превращало категорию в тег-дубликат самой себя в облаке (плюс жёсткий фильтр на бэкенде как страховка); для разовых бытовых дел используется отдельное общее слово вместо имени категории; для эмоций теперь запрашивается конкретное слово из широкого спектра, а не одно и то же по умолчанию.
- На странице заметок/облака убрано вертикальное центрирование, из-за которого шапка (переключатель + фильтр) прыгала при смене контента.
- В подвале всех страниц — номер версии со ссылкой на репозиторий.
