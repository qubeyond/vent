# Changelog

## v0.2.0

- Все операции с LLM — создание записи, перетегирование, правка орфографии/пунктуации — переведены на модель очереди: ответ приходит мгновенно (`status: processing`), сама обработка идёт фоновой задачей. Можно закрыть вкладку сразу после отправки, обработка не прервётся.
- Страница записи опрашивает статус, пока идёт обработка, и показывает индикатор; редактирование/перетегирование недоступны, пока запись не готова. Ошибка обработки (например, недоступен LLM-роутер) теперь не теряется, а показывается на странице записи вместо старого поведения с HTTP 502.
- Улучшен промпт тегирования: имя тега больше никогда не совпадает дословно с названием категории — раньше это превращало категорию в тег-дубликат самой себя в облаке (плюс жёсткий фильтр на бэкенде как страховка); для разовых бытовых дел используется отдельное общее слово вместо имени категории; для эмоций теперь запрашивается конкретное слово из широкого спектра, а не одно и то же по умолчанию.
- На странице заметок/облака убрано вертикальное центрирование, из-за которого шапка (переключатель + фильтр) прыгала при смене контента.
- В подвале всех страниц — номер версии со ссылкой на репозиторий.

## v0.1.0

- Дамп мыслей с LLM-автотегированием, категории тегов («Колесо баланса»), облако тегов и облако слов с фильтрами (дата/теги/текстовый поиск), перетегирование
